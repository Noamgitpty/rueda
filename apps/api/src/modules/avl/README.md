## Oracle de production C12 (US-025, ADR-068)

`internal/production-oracle.ts`, exporté par `index.ts` : `registerProductionOracle(registry)` déclare la tâche périodique `booking_oracle` sur le module BUS (toutes les 24 h, PROPOSÉ). Chaque passe appelle `core.booking_production_oracle_alert()` (migration 0042) : les cinq contrôles de C12 (17 §2.5) sur toute la base, en lecture seule, et une alerte P1 `booking.alert.production_oracle` dans l'outbox si l'un est non nul. Le rapport est lu en fail-closed (`parseOracleReport` : cinq contrôles exacts, somme cohérente) ; le journal ne contient que des comptes. Câblage dans `worker.ts` : US-003.
