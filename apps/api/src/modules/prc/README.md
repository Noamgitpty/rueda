# PRC — Pricing & Quotes (`apps/api/src/modules/prc`)

**PRC — Pricing & Quotes** : devis versionné, jours facturables, lignes, taxes, versions de prix du trip. Dépendances autorisées : CAT, CFG (socle implicite : CFG, AUD, BUS ; source : 17 §2.2 ; §2.1 PRC --> CFG, CAT).

## Responsabilité

D'après 17 §2.2 et §2.6 : devis versionné (PRC-025), même calcul pour l'affichage, le contrat, le remboursement et les jambes ; jours facturables (une seule fonction paramétrée) ; lignes typées (trip fee, protection, extras) ; taxe par ligne et groupe « pour compte de tiers » ; instantané des paramètres (plan de l'hôte, parts de l'assureur) ; versions de prix du trip (BR-MOD-06). PRC ne calcule pas le règlement (STL) et n'encaisse rien (PAY).

État du code (US-202, ADR-125 ; US-704, ADR-129) : **moteur de devis pur et versionné** (`prc.quote/3`, `internal/quote/` ; la version 2 calcule le **trip fee**, US-704 ; la version 3 la **protection du voyageur** et la prime de l'assureur, US-226, ADR-136) et **devis figés en base** (migration `0100_pricing_quote` : `core.pricing_quote`, `core.pricing_quote_line`, `core.pricing_trip_price_version`, commandes `core.pricing_cmd_freeze_quote` et `core.pricing_cmd_version_trip_price`, rejeu complet par la base, **trip fee compris** depuis la migration `0102_pricing_trip_fee` (US-704) ; voir `packages/db/README.md`, « Devis figés »). **Aucune route HTTP dans PRC** : une route de devis est une route de réservation (`SessionGuard` + `TermsGuard`, US-102, `terms-guard-coverage.test.ts`) et PRC ne dépend que de CAT et CFG (17 §2.2) ; elle est portée par le checkout (US-208, AVL, ADR-133), qui utilise l'instantané de `QuoteService` (même instance que la recherche), `freezeQuote`, `PgQuoteStore`, `QUOTE_MESSAGES` et les textes `common.quote.*`. Depuis la migration `0108_booking_checkout` : devis figé avec `expires_at` (`quote_validity_minutes`), gel borné en taille et en débit (`QUOTE_RATE_LIMITED`), rattachement concurrent traduit (`QUOTE_ALREADY_VERSIONED`, interne).

Règles tenues :

- argent : `Money` (`bigint` en unités mineures) ; aucun arrondi local, seuls `multiplyRoundHalfUp`, `allocHost` (via le moteur de règlement) et `sum` de `@rueda/money` ;
- aucune constante de pays : tout vient de `QuoteParams`, lu de CFG ; les tests lisent pays et devises des données ;
- aucune horloge : l'appelant passe l'instant serveur (`platform.now()`) dans `quotedAtMs` et `at` ;
- fail-closed : ligne non nulle sans règle fiscale ou groupe incohérent ⇒ `TAX_CONFIG_MISSING` ; paramètre absent, durée > `max_trip_days`, protection ou assistance sans part d'assureur figée, part hors de [0 ; 1] ⇒ `QUOTE_UNAVAILABLE` ; jambe négative (promotion trop forte) ⇒ `LEG_AMOUNT_NEGATIVE` ; `TRIP_PRICE` ou `TRIP_FEE` fourni par l'appelant, montant d'une autre devise, ligne négative hors promotion ⇒ `QUOTE_INPUT_INVALID` ;
- taxe d'un groupe `third_party` = `true` ⇒ jambe `TAX_THIRD_PARTY` ; défaut `false` ⇒ dans `PLATFORM` (BR-PRICE-12) ;
- protection du voyageur (US-226, `prc.quote/3`, ADR-136 ; 16 PRC-018, PRT-001, PRT-002, PRT-011 ; 08 BR-PRICE-11, E7) : quand le pays vend la protection (`protectionGrid`, paramètre `protection_grid`), la ligne `PROTECTION` est **calculée**, jamais fournie : prix journalier = roundHalfUp(prix journalier net × part du niveau), plancher puis plafond, × jours facturables ; niveau choisi (`protectionLevel`) au moins `guest_protection_min_level` (absent ⇒ plus petit rang), refusé sous l'âge minimal du niveau (`driverAge` déclaré) : `PROTECTION_LEVEL_NOT_ELIGIBLE` ; sans niveau : `PROTECTION_LEVEL_REQUIRED` ; prime due = roundHalfUp(PROTECTION × `insurer_premium_share[niveau]`) dans la jambe `INSURER`, part absente ⇒ `QUOTE_UNAVAILABLE` ; `protectionOptions` liste les niveaux vendus et leur prix ; plan de gains (`hostPlan`) figé avec sa part ; la base rejoue tout (migration 0110) ;
- distance (US-205b, ADR-140 ; 16 LST-012) : champ facultatif `mileage` de la demande (illimité, ou km par jour et prix du km de l'annonce) ⇒ `mileage` du devis (km inclus = km par jour × jours facturables), dans les documents canoniques seulement si la demande le porte (devis antérieurs rejoués à l'identique) ; aucun montant ni aucune jambe ne change ; la base fige la distance de l'annonce et rejoue celle des documents (0118) ;
- trip fee (US-704, 08 BR-PRICE-06, 16 PRC-012) : ligne `TRIP_FEE` **calculée**, jamais fournie ; tranche choisie par les jours facturables (15 % ≤ 6 j, 12 % 7–29 j, 8 % ≥ 30 j, valeurs PROPOSÉES du dépôt, OQ-MK-01), assiette = prix du trip P (les promotions ne la changent pas), minimum du pays ; taxé selon `tax_line_config` ; **entièrement dans `PLATFORM`** (complément de 08 E7), jamais dans `HOST` (08 A02) ni `INSURER` ; barème absent ou incohérent ⇒ `QUOTE_UNAVAILABLE` (jamais un trip fee nul par défaut). La base recalcule F avec **son** barème avant de figer (`core.pricing_trip_fee`, migration 0102) : écart ⇒ `QUOTE_MISMATCH`.

## Ports

Aucun port propre. Adaptateur du port `SearchPricer` de CAT (US-203, ADR-131) : `searchQuotePricer(paramsOf)` (`internal/quote/search-pricer.ts`), devis provisoire `prc.quote/3` non persisté du résultat d'une recherche (protection minimale du pays comprise, N-141) (prix journalier, période et instant lus en base) ; devis impossible ⇒ `null` (annonce exclue par CAT) ; câblé par `main.ts` sur `QuoteService.params`. API publique (`index.ts`) : `PrcModule`, `QuoteService`, `billableDays`, `computeQuote`, `assembleQuote`, `quoteSettlementTrip`, `tripFeeOf`, `COMPUTED_LINE_TYPES`, `freezeQuote`, `replayFrozenQuote`, `resolveQuoteParams`, `searchQuotePricer`, `QuoteError` et leurs types.

Paramètres lus (17 §7.2) : `grace_minutes`, `max_trip_days`, `trip_fee_schedule` (US-704), `host_default_plan`, `host_share_pct`, `delivery_share_pct`, `extras_share_pct`, `insurer_premium_share`, `insurer_roadside_share`, `guest_protection_min_level`, et `protection_grid` (créé par US-226, graine 0111, valeurs de test À DÉCIDER) ; `tax_line_config` du pays (`countries.json`, `taxLines`).
