## Pièges / hypothèses

- Ni Docker, ni OpenTofu, ni PostgreSQL lancés sur le poste de l'auteur : image, répétition, `tofu test`, L0 et int sont prouvés par la CI seulement.
- `scripts/deploy/ecs.sh` et `deploy.yml` n'ont jamais tourné contre un vrai compte (aucun compte) : la stratégie est prouvée en local, la mécanique ECS ne l'est pas. Premier déploiement cloud = préproduction, avec le fondateur.
- Sonde de santé : `GET /brand/content?locale=es` (aucune route `/health` ajoutée : elle aurait été une route publique hors matrice).
- Numérotation : migration `0050`, fixture `9910`. Si `main` reçoit une migration avant la fusion : renuméroter (fichier, en-tête, README, ADR-078, cette passation).
- `migrator` n'a pas `EXECUTE` sur `platform.declared_environment()` : une future migration qui écrirait un compte PSP sous `migrator` échouerait (voulu, fail-closed).
