# Passation US-014 — Internationalisation espagnol / anglais et formats (2026-10-31, agent front-end, claude-opus-5-5)

Branche `story/US-014-i18n`, partie de `origin/main` (f66304f), dans le worktree de l'agent. Rien n'a été poussé.

- **Fait** :
  - Nouveau paquet `packages/i18n` (`@rueda/i18n`), sans dépendance externe (`Intl` seulement) :
    - catalogues `es` (fait foi, « tú ») et `en`, typés : une clé manquante ou en trop fait échouer `pnpm typecheck` ;
    - `CATALOG_VERSION` ;
    - traducteur avec variables obligatoires et pluriels CLDR ;
    - surcharges régionales possibles.
  - Profils de locale es-PA, es-PY et en dans `config/locales.json`. Ce sont des **données** validées au chargement (ADR-024) : séparateurs, symboles, gabarits jj/mm/aaaa, 24 h en es et 12 h en en.
  - `formatMoney` : adaptateur d'affichage seulement. Il reçoit `MinorUnitAmount { amountMinor: bigint, currency, exponent }`, sans dépendre de `Money` (US-015). Il ne fait aucune arithmétique et refuse un `number`.
  - `formatNumber` pour les quantités non monétaires.
  - `formatDate`, `formatTime` et `formatDateTime`, avec un fuseau du véhicule **obligatoire**.
  - `utcOffsetMinutes` et `checkTimeZoneData` : brique du contrôle tzdata de démarrage de 17 §1.3.
  - Détection de la locale : `negotiateLocale` (cookie `locale` → `Accept-Language` → `defaultLocale` de la configuration). Choix explicite : `POST /locale` (`localeChoiceResponse`) dans les deux applications.
  - Outils de test `@rueda/i18n/testing` : `compareCatalogs` et `findForeignStrings`.
  - Dans `apps/web` et `apps/backoffice` :
    - `<html lang>` suit la locale de la requête ;
    - métadonnées et textes viennent du catalogue (`HOME_TAGLINE` et « Consola interna. » ne sont plus en dur) ;
    - `getRequestI18n()` est la seule source de langue ;
    - tests de rendu « une vue = une langue » dans chaque locale configurée.
  - Vérifié à la main avec `next start` :
    - `Accept-Language: en` → `lang="en"` et texte anglais ;
    - `es-PY` → texte espagnol ;
    - cookie `locale=en` prioritaire ;
    - `POST /locale` → 303 et cookie posé ; une valeur inconnue → 400.
  - Documentation : `packages/i18n/README.md`, `docs/glossary.md` (amorcé), `CONTRIBUTING.md` §6, Q-001 dans `QUESTIONS.md`.
- **Reste** :
  - **Sélecteur de langue visible dans l'en-tête** (UX-11). C'est un composant : il attend la bibliothèque et les jetons de design (US-030, US-033) et l'agent design. Le point d'arrivée `POST /locale` est prêt.
  - Tests e2e Playwright 360 / 390 px du critère « aucune chaîne anglaise » : le harnais e2e n'existe pas encore. Les tests de rendu React couvrent le critère en attendant.
  - Q-001 : choisir le séparateur décimal de es-PA. Seules les valeurs de `config/locales.json` changent.
  - Ce qui n'est pas pris :
    - l'équivalent indicatif « ≈ US$ 160 (referencial) » (EC-32), qui demande une conversion et sort de l'affichage seul ;
    - l'arrondi d'affichage PYG en multiples de 1 000 (I18N-005), qui est un calcul de paramètre pays.
  - Contrôle de démarrage tzdata (17 §1.3) : à brancher dans l'API (`checkTimeZoneData` sur des attentes venues de CFG ou d'une fixture), avec le pendant PostgreSQL.
  - Gabarits de notification de l'API (MSG / NTF) : pour consommer ce paquet, l'API compilée par `tsc` devra le résoudre, par un build du paquet ou un chargement direct des `.ts` par Node 26.
- **Prochaine commande exacte** : `pnpm install --frozen-lockfile && pnpm lint && pnpm typecheck && pnpm test:unit && pnpm build && pnpm format:check`. Avant, en bash : `export PATH="/c/Program Files/nodejs:/c/Users/noamm/AppData/Roaming/npm:$PATH"`.
- **Pièges / hypothèses** :
  - Le CLDR de Node rend es-PA en « USD 1,234.56 » et es-PY PYG en « Gs. 1.050.000 ». C'est pourquoi les séparateurs et les symboles sont dans la configuration et non pris d'`Intl`.
  - Les applications sont désormais rendues dynamiquement (lecture des cookies et des en-têtes dans le layout).
  - `defaultLocale` = `es-PA` est PROPOSÉ (DEC-PAYS ouvert). Ce n'est qu'une donnée.
  - Le fragment de détection de `findForeignStrings` fait 4 caractères au minimum. Un mot anglais court isolé ne serait pas détecté.
- **Paramètres créés (17 §7.2)** : aucun. **Entités / migrations** : aucune. Configuration : `packages/i18n/config/locales.json`.
- **Tests ajoutés et état** : tous verts.
  - `@rueda/i18n` : 76 tests (6 fichiers).
  - `@rueda/web` : 11 tests.
  - `@rueda/backoffice` : 11 tests.
- **Décisions** : UXQ-04 appliquée par défaut (« tú » dans l'interface). Q-001 ouverte (format es-PA). Aucun ADR.
