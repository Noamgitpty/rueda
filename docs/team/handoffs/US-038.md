- **Pièges / hypothèses** :
  - `schema.md` ne se génère que sur un vrai PostgreSQL. Sans banc local (interdit à l'agent), on le recopie depuis le journal du job « base de données », entre les marqueurs `----- docs/architecture/schema.md : DÉBUT -----` et `: FIN -----`. Toute migration future le demande.
  - Les trois fichiers générés sont exclus de Prettier : la CI les compare octet par octet.
  - Contrats : `ContractClient` envoie les en-têtes d'un navigateur (sinon la garde anti-robot ralentit la requête ou exige un défi). La limite de débit de la console vaut 0 dans une application dédiée, pour exercer chaque 429.
