## Critères (19 US-310)

1. **Aide visible depuis l'en-tête de chaque écran ; S17 : support, assistance de l'assureur, 911 / Tránsito** : couvert. Numéros lus de la configuration pays (ADR-174), jamais en dur ; absents ⇒ renvoi à l'aide dans l'appli. Depuis le trip : numéros du pays **du trip** (L3-PM-17).
2. **Message hors plage ⇒ réponse automatique dans la langue du compte ; M6 mesuré** : couvert pour la demande d'aide dans l'appli (canal `IN_APP`). WhatsApp et le téléphone du support sont manuels en bêta (SUP-011 MANUEL) ; lien `wa.me` avec le canal WhatsApp (lot C, N-410).
3. **Plage publiée couverte par un planning validé** : défaut fail-closed. Aucune plage publiée (`supportHours` = null) ; production refusée tant que le fondateur ne l'a pas fournie avec son planning (SUP-020, `POUR_LE_FONDATEUR.md` §2.13 bis).

## Décisions PROPOSÉES

- Routes du trip sous `TermsGuard` (comme tout `/trips`) ; S17 public pour l'urgence.
