- **Fait** (critères de 19 US-013) :
  - **Configuration en données** (module CFG, `apps/api/src/modules/cfg/`) : `data/currencies.json` (USD 2, PYG 0), `data/countries.json` (PA / PY : devise, fuseau, locales es-PA / es-PY + en + fr prises dans `@rueda/i18n`, noms es / en / fr, taxe par ligne, entité juridique, fériés, attentes tzdata), `data/params.json` (119 clés de 17 §7.2 hors « historique, sans objet », valeurs PROPOSÉES). Validation fail-closed `parseCountryConfig` (`CONFIG_INVALID`, tous les défauts listés), résolution `resolveParam` (spécificité, dates, `fail_mode`), interrupteurs `isGoLiveSwitchOn` (absent ou inconnu ⇒ `false`), `assertNotRetroactive`. `CountryConfigService` est exporté par `CfgModule`.
  - **`PARAM_RETROACTIVE`** : en TypeScript (`assertNotRetroactive`) et en base (garde de `core.config_param_value` et `core.pricing_tax_line_config`, tous rôles, `platform.now()`).
  - **Clé obligatoire manquante ⇒ refus explicite** : `RUEDA_ENV` absent ou inconnu ⇒ `production` ; le démarrage (API et travailleur, `onModuleInit`) lève `PARAM_MISSING` avec la liste. Vérifié aussi sur le `dist` compilé : `RUEDA_ENV=development node dist/worker.js` sort en 0 ; sans `RUEDA_ENV`, `PARAM_MISSING` (34 manques).
  - **« Aucune constante pays »** : règle ESLint `rueda/no-country-constants` et contrôle SQL des migrations (`packages/config/country-constants/`), tous deux dans `pnpm lint`. Les jetons sont **tirés des données** : un pays ajouté est aussitôt protégé.
  - **tzdata** : contrôle du runtime au démarrage (`TZDATA_MISMATCH`) ; contrôle PostgreSQL `checkPostgresTimeZoneData` + test d'intégration.
  - **Tables** (migration `0002_config_country.sql`, schéma Bêta `core`) : `config_currency`, `config_country`, `config_param_definition`, `config_param_value`, `config_holiday_calendar`, `pricing_tax_line_config`, `finance_legal_entity` ; RLS `ENABLE` + `FORCE`, `migrator_all`, lecture seule `app_api` / `app_worker`, rien pour `app_anon` ; gardes (non-rétroactivité, cohérence, immuabilité, `TRUNCATE`, interrupteur ≠ `false` ⇒ `FORBIDDEN`) ; `core.config_go_live(key, country)`. Graines `0003_config_seed.sql` **générées** depuis les données (test d'égalité).

- **Pièges / hypothèses** :
  - **Numéros de migration 0002 / 0003** : si une autre story fusionne d'abord une 0002, renuméroter (et `SEED_MIGRATION_FILE`, la liste blanche pays).
  - `CREATE SCHEMA IF NOT EXISTS core` : premier objet du schéma Bêta ; une autre story qui ferait `CREATE SCHEMA core` sans `IF NOT EXISTS` échouerait après celle-ci.
  - Défaut fiscal (OQ-BR-14 / OQ-MK-06, « assiette = loyer seul ») : `TRIP_PRICE` **et** les deux lignes promo (loyer net) sont taxables ; les autres lignes non. Les vecteurs de 08 (trips A, D, J, K2) supposent d'autres assiettes : US-016 / US-017 devront tester sur une configuration de test, pas sur ces graines.
  - Choix PROPOSÉS sans source explicite : `min_driver_age` 25 pour la catégorie `PREMIUM` (08 « 25 ans pour la classe Premium ») ; `advance_notice_minutes` 1 440 pour `LUXE` ; réseaux `MASTERCARD` / `VISA` / `AMEX` ; `payout_batch_local_time` en minutes après minuit local (600) ; `insurer_settlement_at` = `MONTHLY` ; `platform_release_at` = `TRIP_PAYOUT_AT` ; clés « plateforme » de 17 §7.2 posées par pays.
  - `platform_funded_host_compensation` **absent** (16 ADM-031), pas `false` comme 17 §7.2 : même effet par `fail_mode` `FALSE`.
  - `core.config_go_live` est `STABLE` comme dans 17 §2.3, bien qu'elle lise `platform.now()` (`VOLATILE`) : instant capturé une fois ; à confirmer en revue.
  - La garde refuse toute écriture d'un interrupteur à une valeur autre que `false`, **migrator compris** : US-125 devra la remplacer par `param_value_go_live_guard`.
  - Le contrôle de présence au démarrage utilise l'horloge du processus (aucune décision de délai n'en dépend).
  - La règle ESLint exempte `**/*.test.*` et `**/test/**` ; `test-helpers.ts` du module CFG n'a pas de constante pays et reste contrôlé.
- **Paramètres créés (17 §7.2)** : 119 définitions ; valeurs PA / PY de tous les défauts chiffrés ; « à fixer » absents (12 clés communes, `commercial_gesture_cap` au PA, 5 clés de rétention au PY) ; interrupteurs à `false`. **Entités / migrations** : `0002_config_country`, `0003_config_seed` (générée), test `9100_test_config_writer`.
