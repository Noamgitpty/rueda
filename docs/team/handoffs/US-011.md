- **Pièges / hypothèses** :
  - **Numérotation** : migrations `0022` à `0026` (main avait `0021` après US-009). Si `main` avance, renuméroter : fichiers, en-têtes, README, ADR-053 et cette passation.
  - Une nouvelle fonction `SECURITY DEFINER` exige trois choses : une entrée dans la liste blanche, un propriétaire NOLOGIN de `OWNER_ROLES` (et de l'amorçage), puis `GRANT CREATE` → `ALTER … OWNER TO` → `REVOKE CREATE` dans la même migration.
