# Passation US-042 — Propriétés monétaires et tests de mutation (2026-11-03, agent back-end, claude-opus-5-5)

Branche `story/US-042-proprietes-monetaires`, worktree `.claude/worktrees/us-042-dev`, PR #70 (brouillon). **Statut : EN REVUE**. Revues exigées : code, **argent**, qa (story, `packages/money/`) et **sécurité** (`.github/`, revue au SHA fusionné, job `revues` vérifié intact), sur un autre modèle que l'auteur. Décisions : ADR-076 (PROPOSÉ).

- **Fait** :
  - **Critère 1** (10 000 cas comparés à l'oracle, 0 écart, 0 violation) : `test/oracle/oracle-diff.oracle.ts` + `oracle_driver.py` (`pnpm --filter @rueda/money test:oracle`). fast-check génère les entrées (USD et PYG, R / NR, promos, 1 ou 2 groupes fiscaux dont tiers, parts quelconques, 11 motifs bêta, bornes de 08) ; le pilote compose `independent_settlement_check.py` et `check_legs.py` (chargé seulement s'il rend « RÉSULTAT : OK ») sans rien calculer. Comparés : primitives, en-tête, lignes, taxe par groupe, jambes de capture / retenues / variation, `negativeLeg`, options A et B, version 1, version n+1, delta. Local et CI : **0 écart sur 10 000 cas** (et 100 000 dans le job de nuit, vert sur la PR). Contrôle de sensibilité : `THREE_QUARTERS` passé à 2/3 ⇒ 2 tests en échec.
  - Propriétés (`test/monotonicity.properties.test.ts`, PA / PY) : monotonie et bornes de `roundHalfUp` / `allocHost`, conservation (`splitHostPlatform`, Σ jambes, `PLATFORM` complément, `INSURER` au plus proche, `TAX_THIRD_PARTY`), remboursement décroissant avec l'heure, FULL tout remboursé, part hôte ≤ retenu.
  - **Critère 2** (mutation ≥ 80 %) : Stryker 10.0.0 sur `src/*.ts` et `src/settlement/*.ts`, seuil bloquant 80 %. Score : 95,26 % (local, complet), 95,67 % (CI, mode rapide). Tests ajoutés pour tuer les survivants : `test/guards.test.ts` (chaque garde de l'API) et `test/settlement/contract.test.ts` (table de décision de 08, origines, fenêtre de no-show, pénalité, dernière minute, refus d'entrée, jambes, clés d'opération).
  - Deux défauts du lanceur Vitest de Stryker 10.0.0 sous Vitest 5, corrigés par `patches/@stryker-mutator__vitest-runner@10.0.0.patch` : (1) filtre de noms (`fullTestName`) — sans lui, 0 test par mutant, tout survit ; (2) un fichier de test qui échoue à l'import n'était pas compté comme échec — faux survivants.
  - CI : `argent-oracles` (PR, main), `argent-mutation` (mode rapide sur PR : rien hors `packages/money/` et `patches/`, fichiers `src/` modifiés seuls, mutants statiques ignorés ; complet sur main et la nuit), `argent-oracles-long` (nuit). `revues` inchangé ; permissions `contents: read`, actions par SHA, aucun secret, aucun `continue-on-error`.
