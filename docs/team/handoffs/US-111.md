# Passation US-111 — Rétention, pseudonymisation et registre Ley 81 (Bêta) (2026-11-13, agent back-end, claude-opus-5-5)

Branche `story/US-111-retention-ley81`, worktree `../wt/US-111`, PR en brouillon. **Statut : EN REVUE (aucune revue lancée).** Revues exigées (`review-requirements.json`, story US-111) : code, architecture, **sécurité**, qa ; **argent conseillée** (rétention des données financières, pseudonymisation des trips). Décision : ADR-118 (PROPOSÉ).

- **Fait** :
  - **Critère 1** (registre non validé ⇒ `KYC_PRODUCTION_BLOCKED_NO_REGISTER`) : `core.privacy_kyc_register_gate` (0090), production ou environnement inconnu ; jugé par l'API avant tout fournisseur (`IdentityStore.registerGate`, 503, texte `common.kyc.providerUnavailable`). Levé seulement si `privacy_register_validated[pays] = true` ET un fournisseur KYC `CONTRACTED` en vigueur inscrit. Prouvé en L0 (PA, PY, pays par pays) et en contrat HTTP (aucune session chez le FAKE).
  - **Critère 2** (trip clos sans litige depuis la durée ⇒ pseudonymisé, purge journalisée) : travailleur `privacy_request` (1 h) → `core.privacy_worker_retention_sweep` ; durée `evidence_retention_months` (≥ 15 mois) depuis la dernière date du trip (fin, mise à jour, opération monétaire) ; motifs C2 → `PSEUDONYMISED` ; `core.audit_retention_log` en ajout seul. Litige jamais ; opération tardive : échéance repoussée ; une seule fois. Prouvé en L0 sous horloge virtuelle (minute avant / après).
  - **Critère 3** (`HANDLE_DSR` ⇒ délai et traitement suivis) : action d'état liée à `core.privacy_manual_action_dsr` (saisie `kind`, `step`), `core.audit_data_subject_request` (échéance `privacy_dsr_response_days`), machine d'états fermée, refus `DSR_*` ; retard signalé une fois (`PRIVACY_DSR_OVERDUE`, P1, par pays). Back-office : formulaire dédié (ADMIN, SUPERADMIN), es / en / fr / pt-BR, catalogue v36.
  - Registre (`audit_subprocessor` : 6 fournisseurs du brief, aucun contractuel ; `audit_processing_activity` : 10 traitements, UXQ-11 ; `audit_retention_rule` : 5 règles) ; effacements KYC en souffrance comptés et alertés (`PRIVACY_KYC_ERASURE_STALE`, suite d'US-106) ; engagements de l'hôte : durée `privacy_vehicle_attestation_retention_months`.
  - Docs : ADR-118, README `@rueda/db`, AUD, KYC, `MONITORING.md`, gabarits `docs/legal/` (registre en espagnol, politique en 4 langues), inventaire des données personnelles, matrice d'autorisations, listes blanches (RLS-15, expand / contract, pays), fragment CHANGELOG.
