## Critères (19 US-213)

1. **« en cours de confirmation » sans adresse exacte, puis confirmé sans rechargement** : déjà livré par 223b (S06 `VERIFYING`, relecture toutes les 5 s) ; l'e2e existant le prouve. L'état confirmé porte maintenant le contenu de S07.
2. **Confirmation au voyageur et à l'hôte, sans doublon au rejeu, sans le téléphone de l'hôte** :
   - **Prouvé** : destinataires lus en base ; un envoi par destinataire et par canal ; rejeu sans doublon (unitaires, intégration sur un trip réel, L0).
   - **Hors d'atteinte avant le lot C** :
     - délai d'une minute : aucun canal réel ; l'envoi est créé dans la transaction du reçu de l'événement ;
     - contrat : le message renvoie à la réservation ; le lien absolu et le PDF joint sont une suite ;
     - constancia : US-212 ;
     - numéros du support et de l'assistance de l'assureur : données du fondateur (§2.13) ; **GL-36**.
