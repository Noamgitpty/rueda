- **Pièges / hypothèses** :
  - `AppData\Local\hermes\node` contient un Node v22.23.2 qui peut passer en tête du PATH.
  - En Git Bash, `$APPDATA` vaut `C:\…` : `"$APPDATA/npm"` casse le lanceur pnpm (`Cannot find module 'C:\Program Files\Git\Users\…\pnpm.cjs'`). Écrire le chemin Unix.
  - Node 26 importe directement les `.ts` de `packages/config/eslint/`, `packages/config/sql-clock/` et `apps/api/src/modules/dependency-graph.ts`. Ces fichiers doivent rester en syntaxe effaçable : pas d'`enum`, pas de `namespace`, pas de propriétés de paramètre. Les imports y portent l'extension `.ts`, sauf dans `apps/api`, qui importe en `.js` (compilé par `tsc`).
  - Vite/Vitest résout les `extends` de tsconfig sans suivre les liens symboliques. C'est pourquoi la base stricte vit dans `packages/config/tsconfig/base.json` et que `tsconfig.base.json` racine l'étend : ne pas inverser.
  - TypeScript reste en **6.0.3** : `typescript-eslint` 8.71 exige `<6.1.0`, alors que TypeScript 7.0.2 existe.
  - La règle de frontières ne voit que les **imports relatifs** ; ne pas introduire d'alias de chemin sans l'adapter.
  - Le lint SQL analyse le contenu des chaînes dollar comme du code. Un `$$now()$$` utilisé comme simple littéral serait donc signalé (faux positif volontaire).
  - Hypothèse « socle implicite » : 17 ne dit pas en toutes lettres que tous les modules dépendent de CFG, AUD et BUS. Il dit (§2.1) que le socle « ne dépend de personne », ce qui garantit l'absence de cycle. L'ajout implicite vaut donc pour les modules hors socle seulement.
  - Écart : CFG publie `config.param.changed` (17 §2.2), ce qui suppose l'outbox (BUS), alors que le socle « ne dépend de personne ». À trancher au moment de câbler l'outbox ; le graphe actuel interdit CFG → BUS.
  - Écart : SUP « tous (lecture) » est codé comme tous sauf RPT, parce que RPT lit tout, SUP compris, et que l'inverse ferait un cycle.
  - Écart : 17 §10 point 3 (Bêta) prévoit une seule application Next.js, le back-office étant le même code sur un domaine distinct. La consigne de US-001 et 17 §6.1 demandent `apps/backoffice` séparé, qui a été créé. Noté dans ADR-001.
  - Préfixe de table D1 : 17 ne fixe pas la forme exacte. Valeur PROPOSÉE : code du module en minuscules + `_` (`avl_trip`), schéma `platform` pour `platform.now()`.
  - Valeurs `Agent-Role` listées dans CONTRIBUTING : PROPOSÉES, à confirmer par US-029 / US-050.
