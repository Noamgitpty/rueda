- **Fait** (critères de 19 US-034) :
  - **Publication atomique, précédente dans l'historique** : `core.cfg_brand_cmd_publish` (0042), sous verrou consultatif, passe l'ancienne version `ARCHIVED` et le brouillon `PUBLISHED` dans la même instruction ; index unique partiel « une seule publiée » ; preuve de 8 publications concurrentes (`l0-brand`).

  - **Lecture mise en cache, invalidée à la publication** : `GET /brand`, `GET /brand/content`, `GET /brand/assets/:id` (CFG) ; cache vidé à chaque publication ou retour arrière, borné à 30 s entre instances ; ETag / 304.
