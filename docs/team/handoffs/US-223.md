## Pièges

- `String.prototype.replace` interprète `$'` dans la chaîne de remplacement : le générateur de la migration utilise `split/join` (un `~ '^[0-9]$'` du SQL recopié dupliquait la fin du gabarit).
- Les tests qui commitent ne doivent jamais ouvrir d'interrupteur : le devis engagé est posé par la fixture 9969.
- `payment_operation_event.at` vaut l'instant de la transaction : l'ordre des événements d'une même transaction n'est pas lisible.
