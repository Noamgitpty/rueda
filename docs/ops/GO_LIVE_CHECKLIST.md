# Liste de contrôle de mise en service (production réelle)

> Créée par US-049 (porte du lot 0, 2026-11-06), à la demande des revues de la PR #92 (sécurité, constat 3 ; architecture, constat 8). **PROPOSÉE.** Elle s'applique **avant le premier déploiement de production** ([DEPLOY.md](DEPLOY.md) §5, étape 3) et **avant que `payouts_enabled` ou `insurer_contract_active` passe à `true` dans un pays**. Elle ne remplace ni la porte de déploiement d'ADR-084 ni la porte de 19 §1.9 point 2. Elle s'y ajoute.
>
> **État constaté au 2026-11-10** : `main` est **protégée depuis le 2026-11-10** (`gh api repos/Noamgitpty/rueda/branches/main/protection`, le 2026-11-10 : **17 statuts exigés**, `enforce_admins` actif (aucune dérogation pour les administrateurs), force-push et suppression refusés, `strict: false`) ; il manque encore un fichier `CODEOWNERS` et la revue obligatoire de ses propriétaires (`required_pull_request_reviews` absent). **Aucun** environnement GitHub (`gh api repos/Noamgitpty/rueda/environments` : vide). Jeton `gh` des agents toujours **administrateur** (`gh api repos/Noamgitpty/rueda --jq .permissions.admin` : `true`). GL-03, GL-05 et GL-06 restent donc non cochables.
>
> **Règle** : une ligne n'est cochée que si sa **preuve** est jointe : lien d'un run CI, sortie d'une commande, SHA, ou fichier du dépôt. Une ligne sans preuve est non cochée, et la mise en service est refusée. Une ligne sans preuve automatique demande la preuve manuelle qu'elle décrit.
