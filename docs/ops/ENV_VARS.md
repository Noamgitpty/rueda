# Inventaire des variables d'environnement et des secrets

> **Noms seulement** : aucune valeur secrète ici ni dans le dépôt (CLAUDE.md « Interdits »). Le dépôt est public. Chaque story qui ajoute une variable la déclare ici (19 §1.4 point 6, US-037).
>
> **Contrôle automatique (US-037, ADR-083)** : `pnpm lint` lance [`scripts/ci/check-env-inventory.mjs`](../../scripts/ci/check-env-inventory.mjs). Toute variable lue ou posée par le dépôt (code TS / JS, scripts shell, compose, workflows GitHub, IaC OpenTofu, Dockerfile, `turbo.json`, `.env.example`) doit figurer dans la **première colonne** d'un tableau de ce fichier, entre accents graves (`PREFIXE_*` couvre une famille). Sinon, le job `qualité` échoue et nomme la variable et son fichier. Inventaire des comptes : [`ACCOUNTS.md`](ACCOUNTS.md).

## Légende

- **Environnements** : `dev` (pile de développement `compose.yaml` ou poste), `test` (tests unitaires, intégration, L0, en local et en CI), `CI` (workflows GitHub), `préprod` (préproduction locale `infra/local` ou cloud), `prod` (production cloud).
- **Propriétaire de la valeur** (qui fixe la valeur ; la variable elle-même appartient au dépôt, donc au fondateur) :
  - **fondateur** : valeur saisie par le fondateur seul, dans le coffre de l'hébergeur ou dans les variables d'un environnement GitHub ; aucun agent n'y a accès (OPERATING_RULES §1) ;
  - **IaC** : posée par `infra/opentofu` dans la définition de tâche (changement par PR revue, appliqué par le fondateur) ;
  - **image** : posée par `docker/prod/Dockerfile` ou `docker/dev/Dockerfile` ;
  - **compose** : posée par `compose.yaml` ou `infra/local/compose.yaml` ;
  - **CI** : posée par un workflow de `.github/workflows/` ;
  - **poste** : choisie par la personne ou l'agent qui lance la commande en local (jamais de secret de production) ;
  - **plateforme** : fournie par GitHub Actions, le runner, Node.js ou une bibliothèque.

## Secrets : où ils vivent, rotation, accès (US-037, 17 §6.6)

Règles : aucun secret dans le dépôt, les journaux, les événements ni l'état OpenTofu (le module ne crée que les **contenants**, `infra/opentofu/modules/environment/secrets.tf`) ; aucun agent ne lit un secret de production (OPERATING_RULES §1) ; la CI analyse les secrets (gitleaks). **Rotation** : runbook [`SECRET_ROTATION.md`](SECRET_ROTATION.md) (US-051, ADR-082), sans coupure (deux valeurs valides ou comptées pendant la transition, puis l'ancienne refusée), exercé tel qu'écrit par la CI (job `rotation-secrets`) ; il remplace la procédure provisoire de l'amorçage.
